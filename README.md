# Weather Dashboard by TeamA
## Installation

### 1. Clone the repository

```bash
git clone https://github.com/kharlamovilya/weatherdashboard.git
cd weatherdashboard
```

### 2. Install dependencies

```bash
npm install
```

### 3. Create a .env file

Create a file named `.env` in the project root directory and add:

```env
OPENWEATHER_API_KEY=YOUR_OPENWEATHER_API_KEY
PORT=3000
```

Replace `YOUR_OPENWEATHER_API_KEY` with your OpenWeather API key.

### 4. Start the backend server

```bash
npm start
```

### 5. Open the frontend

Open the `frontend/index.html` file in your browser.

The frontend will communicate with the backend server running on:

```text
http://localhost:3000
```
